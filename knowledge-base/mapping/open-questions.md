# 待确认事项

以下问题不会阻止先完成已有接口覆盖的页面，但会影响对应功能是否能真实提交。

## 需要后端确认

1. 后台使用邮箱验证码登录，并在登录后校验管理员权限。
2. 生成价格、免费次数、兜底文案是否有尚未写入 OpenAPI 的配置接口。
3. 会员状态/到期时间的操作接口。
4. 角色权限矩阵和审计日志接口。
5. Analytics 是否会补充金币、会员指标及 `non_member`、`member` 用户类型。
6. Dashboard 应复用 Analytics 查询还是会提供独立汇总接口。

## 需要产品确认

1. 用户反馈是否需要独立后台页面。
2. 媒体资产是否只嵌入角色编辑，还是需要独立素材中心。
3. 商业化页面使用固定的“会员/金币包”编辑器，还是完全采用通用商品模型。

# 第一版实现状态

更新时间：2026-08-20

## 已接真实 Admin API

- 角色：列表、详情、创建草稿、保存草稿、发布、版本历史、回滚、资产上下架与移除。
- 媒体：上传凭证、对象存储直传、上传结果登记、媒体列表客户端方法。
- 生成预设：列表、新增、双语编辑、上下架、删除。
- 用户：列表、详情、单用户金币流水、全局用户流水、后台补币（带幂等键）。
- 商品：列表、新增金币包、新增订阅套餐、编辑、上下架、删除客户端方法。
- 会员权益：按语言查询、编辑标题与描述、启停及覆盖保存。
- 统计：Dashboard `all` 查询，数据看板 `user`、`chat` 查询。
- 用户反馈：保留 API 客户端方法；产品需求未定义页面，因此没有擅自增加菜单。

## 保留原型但不伪造接口

- 生成价格、免费额度、失败兜底话术。
- 用户封禁/解封、会员开关与到期调整、重置免费额度。
- 权限矩阵与审计日志。
- Analytics 的金币、会员专用 Tab 及产品稿中更细的用户分层。

上述无接口操作会禁用或显示待接口说明；页面不展示原型数据，也不提供伪保存或伪成功反馈。

## 联调限制

OpenAPI 没有后台登录或获取 Admin Token 的接口。当前页面右上角提供 Admin Token 配置，Token 只保存在当前浏览器；使用有效 Token 后才能完成成功响应联调。已使用无效测试 Token验证 401 状态，页面会显示“Token 已失效”，且不会产生控制台错误。

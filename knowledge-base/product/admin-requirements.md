# 2026.7.24 Emora 后台需求文档

> 来源说明：本文件从原型仓库的 Markdown 需求稿复制，原稿使用旧品牌名 Luma；本项目统一称为 Emora。它描述产品需求，不代表每项能力都已经有对应接口。

# 一、角色管理

## 1.1 角色列表页

**列表字段：**

| **字段** | **说明** | **排序** |
| --- | --- | --- |
| 封面 | 角色封面缩略图 |  |
| 角色名 | 名称 + 副标题，点击进入编辑器 |  |
| 状态 | 已上架 / 草稿；已上架表示 C 端可见，草稿表示改动尚未发布 |  |
| ID | 角色 ID |  |
| 标签 | C 端卡片展示标签，黑色圆角文字标签，≤4 个 |  |
| 今日聊天用户数 | 与数据看板「聊天页 · 各角色聊天明细」同口径 |  |
| 消息次数 | 附人均轮次；同口径 |  |
| 卡曝光 pv/uv | 与数据看板「用户 · 角色卡曝光分布」同口径 |  |
| 生成提交 → 成功率 | 照片/视频合并提交数与成功率；同口径 |  |
| 操作 | 所有角色统一显示【编辑】 | 按最近编辑 |

列表不展示版本号与资产完备度；点击整行或【编辑】均直接进入可编辑表单。状态由保存草稿或上架自动更新，不允许在列表中直接切换。

**顶部操作区：**

* 【导入 JSON】按钮：通过 `chara_card_v2` JSON 创建角色

* 搜索框：支持按角色名或 ID 搜索

## 1.2 导入角色

触发方式：点击【导入 JSON】并选择 `chara_card_v2` 文件。后台不提供手工新增角色弹窗，创建接口继续保留供 JSON 导入调用。

导入期间显示全屏加载并禁止重复提交；创建成功后以草稿状态进入角色编辑器，由管理员继续检查和补充资料。

## 1.3 角色编辑器

**顶部操作区：**

* 【返回列表】：返回角色列表页

* 当前状态：只读标签展示「草稿 / 已上架」，不可直接切换

* 已上架与草稿角色进入编辑器后都可以立即修改，不设置二次【修改】按钮

* 【保存草稿】：所有状态均显示；保存当前改动但不影响 C 端，角色状态更新为草稿

* 【上架】：所有状态均显示；校验通过后替换线上版本并更新为已上架（无评审环节）

**左侧角色卡摘要：** 封面大图、角色名、副标题，以及该角色的数据指标（今日聊天用户数、消息次数含人均轮次、卡曝光 pv/uv、生成提交→成功率），与角色列表及数据看板同口径；不显示状态、版本、资产完备度。

### 1.3.1 角色资料 / Profile

| **字段** | **类型** | **必填** | **说明** |
| --- | --- | --- | --- |
| Avatar / 封面 | 本地上传 | 是 | 本地图片上传并即时预览，可更换 |
| Name / 名称 | 文本输入 | 是 | 角色名 |
| Tagline / 一句话定位 | 文本输入 | 否 | ≤50 字符，C 端角色卡辅助定位 |
| 标签 | 文本输入 | 否 | 双语，≤4 个 |
| Description / 角色简介 | 多行文本 | 否 | 以角色自己的声音写，资料页与发现卡可见；前端显示实时字符数，不限制历史内容编辑 |
| Avatar notes / 视觉备注 | 多行文本 | 否 | 内部可见；记录风格、情绪、表情和颜色，不进入模型上下文 |
| AI 标识 | 常量展示 | — | 不可关闭，不伪装真人原则 |

### 1.3.2 开场白 / Greetings

| **字段** | **类型** | **必填** | **说明** |
| --- | --- | --- | --- |
| Primary Greeting | 多行文本 | 是 | 主开场 first_mes；新会话默认使用，重置对话恢复此条；中英双语；每种语言 ≤4,096 字符 |
| Alternate Greetings | 动态列表 | 否 | 主开场之外最多 5 条；每条中英双语、可启停、可删除；每种语言 ≤4,096 字符 |

**规则：**

* 每条备选开场必须提供与其他开场不同的场景、动作或用户切入点

* 开场白直接进入场景，使用角色自己的声音，并给用户一个易回应的问题、动作或选择

### 1.3.3 角色定义 / Character Definition

运营只维护最终提示词，不提供创作规划、定义结构、对话示例、行为规则或预览等重复板块。

| **字段** | **类型** | **必填** | **说明** |
| --- | --- | --- | --- |
| 中文提示词 | 大型多行文本 | 是 | 最终交给模型的中文角色提示词；支持 `{{char}}` / `{{user}}`；最大 32,000 字符 |
| English Prompt | 大型多行文本 | 是 | 最终交给模型的英文角色提示词；支持 `{{char}}` / `{{user}}`；最大 32,000 字符 |
| 字符统计 | 只读 | — | 当前语言实时显示 `n / 32,000` |

**规则：**

* 中文、英文通过顶部语言切换维护，切换时不丢失当前输入

* 已上架角色进入编辑器后可以直接修改；只有保存草稿或上架才记录本次编辑结果

* 发布仅校验：中英文提示词非空且未超限；主开场中英文非空且未超过 4,096 字符

* 校验失败时点击【上架】停留在角色定义 Tab 并提示补充，不改变版本状态

* 运行时记忆、安全兜底、金币、亲密度及其他系统配置不在此维护

### 1.3.4 视觉资产

分「公开资产」「私密资产」两个子 Tab。

| **子 Tab** | **内容** |
| --- | --- |
| 公开资产 | 封面 + Gallery 图片 |
| 私密资产 | 私密照片 + 视频封面 |

**网格字段：**

| **字段** | **说明** |
| --- | --- |
| 缩略图 | 图片预览；私密照片展示独立模糊预览图 |
| 状态标签 | 已上架 / 已下架，显示于缩略图左上角 |
| 类型 | 封面 / Gallery / 私密照片（含 40 金币标识）/ 视频封面 / 上传图片 |
| 状态开关 | 逐张上下架，即时生效 |
| 删除 | hover 缩略图显示 ×，点击后二次确认移除 |

**规则：**

* 每个子 Tab 尾部为上传位，支持多选本地图片，上传后即时出现在网格中

* 删除需二次确认，确认后 C 端对应展示同步消失

* 私密照片统一定价 40 金币，必须生成独立模糊预览衍生图，原图存私有存储

* 私密素材不得被生成器或其他未解锁页面引用

## 1.4 版本流转规则

* 版本状态机：草稿 → 已上架 → 编辑并保存为新草稿 → 再次上架；仅草稿、已上架两种列表状态，无评审环节

* 已上架角色点击【编辑】后可以立即修改；保存草稿后状态更新为草稿，原线上版本持续生效，直至新草稿上架

* 每次发布保存完整快照，支持一键回滚与版本间 diff

* 上架后新会话立即生效；进行中的会话沿用启动时版本直至会话重置

* 未发布草稿的任何改动不影响 C 端

| OOC / 违法内容 | 出戏或违法内容的拒答 |

**规则：**

* 高危命中时退出角色扮演，直接发送固定话术，不经大模型生成

* 命中与发送记录留痕

# 四、商业化配置

## 4.1 金币包

6 档，直接编辑，点【保存】后生效并同步失效 C 端缓存。

**列表字段：**

| **字段** | **说明** |
| --- | --- |
| 档位 | pack_id |
| 基础金币 | 可编辑 |
| 赠送金币 | 可编辑，C 端展示为「额外赠送 +N」条 |
| 价格 | 可编辑，CNY |
| 状态 | 上下架开关；下架后 C 端钱包页即时消失且不可发起购买 |

**规则：**

## 4.2 订阅套餐

月 / 季 / 年三卡，字段直接编辑，各卡点【保存】后生效。

| **字段** | **说明** |
| --- | --- |
| 价格 | 月 ¥38 / 季 ¥98 / 年 ¥328 |
| 续费价格 | 默认与价格一致，用于首购优惠价与续费价分离 |
| 划线价 | ¥58 / ¥174 / ¥696，须与活动配置一致才可展示 |

* 续费自「当前时间与当前到期日较晚者」起按套餐时长顺延

# 六、数据看板

## 6.1 结构

**顶部操作区：**

* 日期范围选择：开始日期 / 结束日期两个原生日期控件，默认当天；不可选未来日期（max=今天）；开始晚于结束时自动对调；顶部显示范围文案（如「2026-07-18 ~ 2026-07-24 · 共 7 天」）；KPI 行与明细表按 范围天数 N × 日波动系数（开始日期 hash 映射 0.90–1.10）× 用户类型系数 确定性联动，百分比与人均值不缩放

* 用户类型筛选：全部 / 游客 / 非会员 / 会员，按 DAU 占比折算子集（游客 ×0.32、非会员 ×0.56、会员 ×0.13）；选「游客」时金币与会员页转化 Tab 标注「游客不产生付费数据」，仅保留趋势表

* 四个 Tab：用户 / 聊天页 / 金币 / 会员页转化，默认「用户」Tab

每个 Tab 由 KPI 行 + 主题明细表 + 近 7 日趋势表组成；趋势表固定显示近 7 日，不随筛选变化（表头注明）。

# 七、系统设置

## 7.1 权限矩阵

5 角色 × 7 模块，单元格为可编辑 / 只读 / 无权限。

| **角色** | **权限概要** |
| --- | --- |
| 超管 | 全部模块 + 权限管理 |
| 运营 | 仪表盘、角色管理、用户管理、商业化、数据看板 |
| 内容 | 角色管理、生成预设 |
| 审核 | 用户管理（封禁处置） |
| 只读 | 全部页面只读 |

**规则：**

* 高危操作（后台补币、会员状态修改、封禁）仅超管与运营可执行

* 越权访问返回 403 且留痕

## 7.2 审计日志

**列表字段：**

| **字段** | **说明** |
| --- | --- |

| 操作人 | 后台账号 |

**规则：**

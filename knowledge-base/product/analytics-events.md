# Emora 数据埋点

> 来源说明：本文件来自现有原型资料，用于说明统计口径；能否在后台查询，以 `/admin/analytics/query` 的实际字段和枚举为准。

## **2. 数据埋点**

### **2.1 用户**

|      | **环节**   | **统计数据**                            | **数据说明**         | **对应指标** | **取数来源** | **埋点事件**                |
| ---- | ---------- | --------------------------------------- | -------------------- | ------------ | ------------ | --------------------------- |
| 1    | App 启动   | 每日启动 App 的去重用户数、人均启动次数 | 区分游客/非会员/会员 | DAU          | 前端         | `app_open`                  |
| 2    | 角色卡曝光 | 卡片曝光 pv/uv                          |                      | 角色曝光量   | 前端         | `home_character_impression` |

### **2.2 聊天页**

|      | **环节**         | **统计数据**                                                 | **数据说明**                    | **对应指标**   | **取数来源** | **埋点事件**                                                |
| ---- | ---------------- | ------------------------------------------------------------ | ------------------------------- | -------------- | ------------ | ----------------------------------------------------------- |
| 1    | 角色聊天         | 每日打开聊天页的用户数； 每日每个个角色被用户发消息的人数、次数 |                                 | 每日聊天用户数 | 前端         | `chat_view`                                                 |
| 2    | 预设选择         | 各标签选择占比、自定义描述占比                               | preset=custom 单独统计          | 预设偏好       | 后端         | `media_generation_submit`                                   |
| 3    | 生成提交和成功   | 提交量、成功率                                               |                                 | 生成成功率     | 后端         | `media_generation_submit`、`media_generation_result`        |
| 4    | 私密照片点击解锁 | 点击率、解锁率                                               | error_code=insufficient_balance | 私密解锁转化   | 前端+后端    | `private_photo_unlock_click`、`private_photo_unlock_result` |

### **2.3 金币**

|      | **环节**     | **统计数据**                           | **数据说明**                         | **对应指标**       | **取数来源** | **埋点事件**                                    |
| ---- | ------------ | -------------------------------------- | ------------------------------------ | ------------------ | ------------ | ----------------------------------------------- |
| 1    | 钱包曝光     | 每日进入金币钱包人数（区分来源）       | 来源：个人页/聊天金币不足弹窗/会员卡 | 钱包到达率         | 前端         | `coin_store_view`                               |
| 2    | 支付金币包   | 各档位支付人数与占比                   | pack_id、coins、bonus、price         | 档位偏好           | 后端         | `coin_pack_purchase`                            |
| 3    | 支付成功     | 每日付费人数、金额                     |                                      | 付费转化率         | 后端         | `coin_purchase_result`                          |
| 4    | 金币消耗     | 解锁私密照片/生成照片/生成视频消耗分布 | 按 type 分层统计                     | 付费用户金币消耗率 | 后端         | `coin_transaction`（钱包账本事件）              |
| 5    | 金币不足拦截 | 每日弹窗曝光人数                       | 解锁/照片生成/视频生成               |                    | 前端         | `coin_store_view`（source=insufficient_dialog） |

### **2.4 会员页转化**

|      | **环节**      | **统计数据**                           | **数据说明**                                  | **对应指标**       | **取数来源** | **埋点事件**                             |
| ---- | ------------- | -------------------------------------- | --------------------------------------------- | ------------------ | ------------ | ---------------------------------------- |
| 1    | 会员中心曝光  | 每日进入会员中心次数（区分来源）       | 来源：首页图标/个人页卡/金币页卡/免费额度弹窗 | 会员页到达率       | 前端         | `membership_view`                        |
| 2    | 套餐选择      | 月/季/年套餐支付占比                   | plan_id                                       | 套餐偏好           | 后端         | `membership_plan_select`                 |
| 3    | 开通/续费成功 | 每日开通人数、续费人数、续费率         | type=subscribe/renew                          | 会员转化率、续费率 | 后端         | `membership_purchase_result`             |
| 4    | 会员到期      | 每日到期人数、到期 7 日内续费/流失占比 | 以 expire_at 服务端推导                       | 会员留存           | 后端         | `membership_expire`（服务端推导）        |
| 5    | 免费额度用尽  | 每日配额弹窗曝光人数                   | 10 条免费消息用尽触发                         | 配额拦截           | 前端         | `membership_view`（source=quota_dialog） |
